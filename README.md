# pulso · Pregúntale a España

Versión publicada de **pulso**: población sintética de España (25.000 personas, INE + ECV + CIS) que predice cómo
respondería la sociedad española a una pregunta, campaña o test A/B, por comunidad, sexo, edad y otros grupos,
con un semáforo de confianza validado frente a encuestas reales del CIS.

Esta versión muestra resultados ya calculados con el motor local (modelos entrenados con microdatos CIS y un LLM local).
Datos sintéticos · resultados experimentales · GenAI Mavericks (Accenture), reto 3.
